# План Caraxes Pro HUB

В текущей сборке есть слои, действующий профиль Caps для Windows, визуальный
тест клавиш и RGB-холст с USB-предпросмотром. Дальше нужно подтвердить запись
слоёв Base/Fn в устройство и проверить сохранение поклавишного рисунка в
памяти клавиатуры. Подробности реализованного этапа в [HANDOFF.md](HANDOFF.md).

## Слои клавиш

- Добавить базовую раскладку и слои удержания для `Caps Lock`, `Fn1` и
  `Fn2`. При физическом зажатии клавиши на схеме сразу виден её слой,
  при отпускании отображается базовая раскладка. Слой также можно выбрать
  мышью для просмотра и редактирования всех его назначений.
- На схеме показывать итоговое действие на каждой клавише. Выделять
  переключатель слоя, зажатые клавиши и обычные модификаторы `Shift`,
  `Ctrl`, `Alt` и `Win`. Помечать назначения, унаследованные с базового слоя,
  и показывать, как зажатый модификатор меняет результат комбинации.
- Назначения редактируются на схеме и сохраняются в профиле HUB. Первый
  готовый профиль должен воспроизвести текущий `caps.ahk` и позволить
  пользоваться этой раскладкой без отдельного процесса AutoHotkey.

### Переназначение только Caraxes в Windows

Цель — работа слоёв в браузере и других приложениях, пока HUB открыт.
Остальные клавиатуры должны продолжать обычный ввод даже при зажатом
на Caraxes модификаторе слоя.

1. Проверить отдельный подписанный фильтр на клавиатурных USB-коллекциях
   Caraxes `258A:0049`, `MI_00` и `MI_01/COL04`. Фильтр должен отдавать HUB
   источник события и пропускать обычные нажатия при закрытии HUB. Проба
   Interception от 23 ноября подтвердила подключение драйвера только к
   `COL04`, но ни один из его десяти каналов не вернул ID клавиатуры.
   Установленный драйвер привязывает каналы к индексам Windows 0–9.
   После проверки в системе были видны индексы до 22. Фильтр снят,
   обе коллекции снова в штатном стеке. [Поустройственные фильтры Windows](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/installing-a-filter-driver)
2. Подключить профиль к этому источнику ввода. Обычные события пускать по
   штатному маршруту, а клавиши слоя и переназначенные события обрабатывать
   внутри HUB. При отключении клавиатуры или завершении HUB возвращать
   обычный ввод. Состояние точечного режима подтверждать до включения,
   без автоматического перехода на глобальный перехват.
3. На одной Caraxes проверить `Caps + W` в приложении вне HUB, отпускание
   модификатора при переподключении и выключение режима. Для проверки
   изоляции повторить сочетание при одновременном вводе от другого
   доступного HID-источника. Подсветка Caraxes и ввод мыши проверяются отдельно.

Штатный USB-запрос таблицы клавиш уже читается. Сохранение произвольных
слоёв в памяти этой ревизии требует отдельного подтверждения. Для режима
с открытым HUB этого подтверждения можно не ждать, если поустройственный
фильтр пройдёт проверку.

### Радио 2,4 ГГц

- Слои и сохранённые назначения должны работать через USB-приёмник 2,4 ГГц,
  пока HUB открыт. Без кабеля Caps, W и левый Shift пришли через
  `25A7:FA70 / MI_00`. Тест клавиш принимает этот идентификатор только при
  совпадении с точным путём приёмника, сохранённым на ПК.
- Привязать фильтр только к подтверждённому интерфейсу Caraxes. Проверить
  `Caps + W → ↑` в браузере, отпускание слоя при отключении, восстановление
  после переподключения приёмника или пробуждения клавиатуры и обычный ввод
  после закрытия HUB. При отдельном нажатии Fn1/Fn2 служебные события по
  радио не получены. У приёмника есть один 8-байтовый Feature-отчёт. Канал
  для настроек и кадров RGB по радио пока не подтверждён.
- Восстановление штатного «Цветения» с чтением и отменой проверено по USB.
  После перехода на 2,4 ГГц пользователь подтвердил тот же цвет подсветки.
  `Caps + W` отправляет `ArrowUp` в отдельном окне Windows при HUB в трее.
  У штатной утилиты V1.6.6 при подключении только по радио нет обращений к
  Feature-отчётам приёмника, даже при подстановке его VID/PID в копии
  конфигурации. Для управления RGB нужен подтверждённый протокол именно
  этой ревизии приёмника или трасса утилиты, которая меняет RGB по 2,4 ГГц.

### Профиль из `caps.ahk`

| Клавиши в слое Caps | Действие |
| --- | --- |
| `1`–`0`, `-`, `=` | `F1`–`F12` по порядку |
| `[`, `]` | `Home`, `End` |
| `W`, `A`, `S`, `D` | `↑`, `←`, `↓`, `→` с сохранением зажатых модификаторов |
| `P`, `/` | `Print Screen`, `Delete`. Для `Print Screen` сохраняются зажатые модификаторы |
| `;`, `'`, `L` | Громкость ниже, выше, выключить звук |
| `,`, `.` | Предыдущий и следующий трек |
| `Esc` | Обратная кавычка. С `Shift` или `Ctrl` используется ветка с `~`, причём `Shift` имеет приоритет. Ветка `Ctrl` сохраняет модификаторы |

Одиночное нажатие `Caps Lock` оставляет Caps Lock выключенным. Отпускание
сбрасывает слой. Воспроизвести это поведение вместе с навигацией,
медиаклавишами и сочетаниями вроде `Caps + Shift + W`.

### Проверка на USB

1. Зафиксировать исходные назначения и проверить отдельно события нажатия
   и отпускания `Caps`, `Fn1` и `Fn2`. Доступность живого просмотра для
   `Fn1` и `Fn2` зависит от событий, которые передаёт клавиатура. Выбор
   слоя мышью даёт доступ к редактору независимо от этого.
2. Проверить, какие слои можно считать и записать штатно. Для Caps
   предусмотреть обработку внутри HUB на Windows, если хранение такого
   слоя в клавиатуре недоступно. Проверить область действия с подключённой
   второй клавиатурой, отпускание слоя при отключении Caraxes и выходе из
   HUB, а также сохранение штатных комбинаций `Fn1` и `Fn2`.
3. Сверить действия готового профиля с `caps.ahk` и проверить живую схему
   на настоящих клавишах. Сохранить исходные настройки перед записью в
   устройство и подтвердить запись и возврат повторным чтением.

## Поклавишное рисование RGB

- Использовать схему Caraxes как холст. Каждая управляемая клавиша служит
  пикселем. Выбрать цвет и рисовать нажатием или перетаскиванием по клавишам.
- Добавить палитру, ластик для выключения отдельной клавиши, отмену и
  повтор мазка. Показывать рисунок в HUB и сохранять его как локальный
  пресет для повторного открытия.
- По USB подтвердить адреса светодиодов и доступную цветовую палитру.
  Проверить рисунок из нескольких разнесённых клавиш с разными цветами на
  физической клавиатуре. Добавить явное применение и возврат прежней
  подсветки. При наличии поддержки устройства отдельно оценить живой
  предпросмотр на клавиатуре и покадровую анимацию.
